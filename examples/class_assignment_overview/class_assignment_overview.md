# Class assignment overview

This example lists the active classes available to the authenticated teacher and the assignments of each class. When `createClass` is enabled it first creates a new class.

## Prerequisites

- Ballerina Swan Lake 2201.12.0 or later
- A Flat access token. See the [setup guide](../../ballerina/README.md#setup-guide).
- Create a `Config.toml` in this directory:
  ```toml
  flatAccessToken = "<your-access-token>"
  createClass = false
  newClassName = "Music Theory 101"
  ```

## Run the example

```bash
bal run
```
